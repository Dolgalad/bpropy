# `bpropy` backpropagatable belief propagation python package
My thesis work focuses on using Markov Random Field models for solving Integer Linear programs. This project contains implementations of all tests performed for writing my thesis manuscript. It is split into two main submodules; `bpropy.co` contains interface definition for the classes of problems that are of interest for my work: the Maximum Independent Set and Set Covering problem, and `bpropy.mrf` contains routines for defining graphical models and running inference on them. 

All experiments performed and presented in my work should be reproducible by anyone. You will find a description on how to run all tests in the Experiments section of this documentation.
